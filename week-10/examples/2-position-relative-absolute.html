position: relative + absolute

Slides 6 e 7 — Aula 1, Semana 7. Compare os dois cards: a única diferença é o position: relative no pai.

❌ Sem relative no pai

.card-errado { /* sem position: relative */ } .selo { position: absolute; top: 8px; right: 8px; }
Novo Card sem position:relative — o selo se posiciona em relação à página inteira.

✅ Com relative no pai

.card-certo { position: relative; } .selo { position: absolute; top: 8px; right: 8px; }
Novo Card com position:relative — o selo fica certinho no canto deste card.
