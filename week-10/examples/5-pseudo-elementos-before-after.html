Pseudo-elementos: ::before e ::after

Nenhum destes elementos existe no HTML — foram criados só com CSS.

::before — aspas decorativas

.citacao::before { content: '\2018\201C'; position: absolute; color: #52E8CC; }
O melhor jeito de aprender CSS é praticando um pouco todos os dias, mesmo que sejam só 20 minutos.

::after — selo "Novo"

.produto.novo::after { content: 'NOVO'; background: #FFD166; }
